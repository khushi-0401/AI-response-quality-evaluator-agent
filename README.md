# DELL-Sandbox: AI Response Quality Evaluator Backend

Welcome to the **AI Response Quality Evaluator** project. This repository contains the standalone data ingestion system designed to capture, validate, and audit text outputs generated by AI models. 

This project is built using modern Python frameworks and follows professional architectural standards for production-ready backend APIs.

---

##  Features (Module 1)
- **Data Guardrails:** Strict data parsing and structural verification using Pydantic schemas.
- **Relational Storage:** Seamless logging into a localized SQLite ledger database via SQLAlchemy ORM.
- **Unique Ingestion Tokens:** Automated, real-time generation of secure tracking IDs (`UUID`) for every logged AI submission.
- **Interactive Documentation:** Fully-featured, plug-and-play Swagger browser dashboard for immediate sandbox endpoint testing.

---

##  Technology Stack
- **Framework:** FastAPI
- **Data Validation:** Pydantic v2
- **Database Engine:** SQLite
- **ORM Mapping:** SQLAlchemy 2.0
- **ASGI Server:** Uvicorn
